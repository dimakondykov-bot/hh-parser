# Шпаргалка по установке окружения

### venv

 Создание виртуального окружения

```shell
py -m venv .venv
```

Активация

```shell
.\.venv\Scripts\activate 
```

### pip

Обновление пакетного менеджера

```shell
py -m pip install --upgrade pip 
```

### poetry

Установка poetry

```shell
pip install poetry
```

Установка зависимостей проекта

```shell
poetry install
```
